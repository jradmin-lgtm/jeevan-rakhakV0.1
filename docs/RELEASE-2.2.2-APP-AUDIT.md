# 2.2.2 APK release: four-point pre-commit audit

10 October 2026, IST. Scoped to the authorised mobile UI proportion update and removal of duplicate request images.

## 1. Security

Exact production APK scan: no configured private credential values or scanned credential signatures found. Both APKs retain the existing signing identity for compatible upgrades, use production HTTPS endpoints, disable debug/cleartext and contain four ABI libraries. Intentional public Maps-key exposure and legacy signing history remain accepted, unresolved risks. No new permissions, private credential distribution or paid services introduced.

## 2. Controls and integration

Derived source inventory: 402 controls in 201 source files, no missing-handler findings. Final AST comparison: 284 on-prefixed JSX callback attributes across 36 UI files unchanged against the release baseline. All Pregnancy, Referral and OPD radio options were tapped in the normal QA app; exactly one selected radio and the matching category explanation were observed each time. Hindi 130% text at 320 logical pixels stacks the options and retains a working selection. Prior isolated normal-APK booking, area edit/clear, driver acceptance, arrival, OTP, navigation, completion and cancellation-wait evidence remains in the proportions audit. These checks do not mean all 402 controls were executed.

## 3. Regression evidence

Workspace typechecks: 10/10 successful. Supplied/loud gate: 2/2 green. Source hashes match both checkouts for the exact 42 release files. Both production APKs passed certificate, version/runtime, architecture, endpoint and harness-exclusion checks. Android 11 replacement installs from 2.2.1/code 55 to 2.2.2/code 56 preserved an app-private test marker and reached login. Android 15 replacement installs passed; initial startup screenshots showed a System UI ANR, identified in Android event logs before the app starts. Repeated app checks are retained separately. Physical Infinix, authenticated-session migration and background alert audibility remain unverified. The prior 50-ride workload was not rerun for this UI-only change.

## 4. Scope and release hygiene

Exactly 36 UI files and six native version files are selected in the managed release checkout. No API, realtime or portal code changes. No change to coverage, ops access, booking categories, external endpoint paths or signing identity. Backups, credentials, generated builds and unrelated primary checkout edits are excluded. Added lines contain no em dash and the diff whitespace check passes. Public publication requires actual download hash matching after upload; this pre-commit audit is not a claim of publication.

## Edge review

Empty states retain previous captured evidence. Boundary checks cover narrow Hindi/larger text and version upgrades. Concurrency and failure/reconnect evidence is inherited from unchanged business logic, not rerun here. Malformed-release guards reject version, signature and hash mismatch. Screen scale is covered by the 31 page/state layout comparisons, not 50 real phones. Permission evidence covers signed replacement installs; physical sound/DND behavior remains unverified.

## Judgment

Scoped APK release review: 87/100. Strong source-scope, layout, callback, package and upgrade evidence supports publishing for controlled testing. Deductions reflect physical-device and background-notification gaps plus the Android 15 emulator system-service instability. This is not a whole-system launch score and does not resolve previously accepted infrastructure or key risks.
